# PaneShift v0.1.0

First public release of PaneShift.

## Highlights

- Keyboard-first window management for Windows, including ultrawide-friendly thirds and two-thirds.
- Halves, corners, thirds, two-thirds and sixths; Maximize, Center and Restore.
- Configurable shortcuts and repeated half-shortcut cycling through 1/2, 2/3 and 1/3.
- Configurable window gaps, multi-monitor placement and per-monitor DPI support.
- Native Settings UI, tray controls and safe JSON reload.
- Optional start at sign-in from General settings or the tray.
- Explicit restart as administrator for managing elevated windows.

## Downloads

- `PaneShift-0.1.0-Setup-x64.exe` — per-user installer.
- `PaneShift-0.1.0-win-x64.zip` — extract all files and run `PaneShift.App.exe`.
- `SHA256SUMS.txt` — checksums of the final downloads.

## Security

This initial release is currently unsigned. Authenticode signing through SignPath Foundation is planned for future releases. No private signing keys are stored in Git.

VirusTotal links are appended by the release workflow when submissions succeed. Detection results are informational; no scan result is assumed in this template.

## Requirements

Windows 11 x64. The .NET runtime is included. Exit any running copy before installing or switching builds. User configuration survives uninstall.

# PaneShift v0.1.1

## Highlights

- Repeat a third or two-thirds shortcut to move horizontally without changing the layout size.
- Ctrl+Alt+D cycles left → center → right → left at one-third width; Ctrl+Alt+E follows the same sequence at two-thirds width.
- Ctrl+Shift+Win+Up/Down cycles right → center → left → right in the top/bottom sixth row.
- All configurable third, two-thirds and sixth actions support cycling. Left-starting actions move left → center → right; center-starting actions move center → right → left; right-starting actions move right → center → left.
- Each shortcut starts at its named position. Changing the action or target window, pausing, successfully applying/reloading settings, or a failed command resets the cycle.
- Existing half-size cycling, gaps and original Restore history are preserved.
